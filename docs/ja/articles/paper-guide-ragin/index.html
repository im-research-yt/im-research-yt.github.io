論文ガイド:「成功の条件」をどう評価するか(Ragin, 2006)

QCA
notes
成功企業の共通点は、成功の条件といえるのか。Ragin (2006) を通して、必要条件と十分条件の違いと、その関係を評価する一貫性とカバレッジを、MBA の院生とビジネスの分析者向けに読み解く論文ガイド。
Published

October 15, 2026

書誌情報: Ragin, C. C. (2006). Set relations in social research: Evaluating their consistency and coverage. Political Analysis, 14(3), 291-310. https://doi.org/10.1093/pan/mpj019

要点: 「ある条件があれば成功する」と「成功するにはその条件が必要だ」は、別の主張です。この論文は、この違いを集合の関係(十分条件と必要条件)として捉え、その関係がどれほど一貫しているかを一貫性(consistency)で、どれほどの範囲をカバーしているかをカバレッジ(coverage)で評価する方法を示しています。「成功要因」という言葉の中身を問い直したい人に、薦めたい論文です。

概要

　成功企業の多くが顧客志向だったとして、顧客志向を徹底すれば成功する、といえるでしょうか。この問いに関わる論理上の問題を、Ragin は扱っています。

　Charles C. Ragin は、QCA を提唱した社会学者として知られています。この論文の出発点は、理論が述べている関係と、分析で確かめている関係は、一致しているのかという問いです。

　たとえば、「民主主義国どうしは戦争をしない」という主張を考えます。この主張は、「民主主義国どうしの組み合わせは、戦争をしない国の組み合わせの一部である」という、集合の関係を述べています。一方、民主主義国どうしでなくても、戦争をしない国の組み合わせは数多くあるため、「民主主義国どうしであること」と「戦争をしないこと」の相関は、強くならないことがあります。しかし、そのことで、もとの主張が否定されるわけではありません。

　これらを踏まえ、Ragin は、集合の関係で述べられた理論が、分析では、相関についての仮説に置き換えられがちだと指摘します。そのうえで、集合の関係を、その形のまま評価するための、簡単な記述的指標を示しています。

この論文を選んだ理由

　MBAでの研究では、ある事象の発生メカニズム、たとえば企業が成功した際の要因を分析したいことがあります。ただし成功企業の共通点を、そのまま成功の法則と見なせないことがあります。

　経営の事例でいえば、「成功企業は顧客志向を徹底している」「高業績の店舗は接客がよい」といった説明に出会います。しかし、そこから何が言えるかを判断するには、次の3つの問いを区別する必要があります。

  • その条件を備えれば、成功しているのか。
  • 成功するには、その条件が不可欠なのか。
  • その条件で説明できる成功事例は、全体のどれほどなのか。

　この論文を読む意義は、QCA の指標を覚えることだけではありません。「成功要因」という言葉の中身を明確にし、主張に合った証拠を求める視点を身につけられることにあります。QCAを使うか否かにかかわらずMBA の院生として知っておきたい視点が書かれている論文として、薦めたい論文です。

この論文の骨子

　この論文は、集合の関係を評価する2つの指標(一貫性とカバレッジ)を中心に、その使い方までを論じています。このメモでは、4つの点に絞ります。

1. 相関と集合の関係は、別の問いに答える

　相関は、2つの変数がどのように連動しているかを見ます。集合の関係では、ある条件を備えた事例の集まりが、結果を達成した事例の集まりに含まれるか(あるいは、その逆か)を見ます。条件を \(X\)、結果を \(Y\) とすると、十分条件と必要条件は、次のように区別できます。

関係 問い 集合としての表現
\(X\) は \(Y\) の十分条件 X があれば、Y があるか \(X \subseteq Y\)
\(X\) は \(Y\) の必要条件 Y があるなら、X があるか \(Y \subseteq X\)

　たとえば、「好立地と優れた接客の組み合わせを備えた店舗は、高業績である」という主張を考えます。これは、「この組み合わせを備えた店舗の集まりは、高業績の店舗の集まりに含まれる」という、十分条件の主張です。この主張が述べているのは、組み合わせを備えた店舗が、高業績になっているかどうかだけです。逆向きの「高業績の店舗は、すべてこの組み合わせを備えている」とは、述べていません。たとえば、立地は平凡でも、独自の商品構成と強いブランド力で高業績を実現している店舗があるかもしれません。そうした店舗は、この主張の外側にあるだけで、主張に反する例にはなりません。(この記事の店舗の例と数値は、説明のための架空の例です。ただし、17/20 = 0.85 という数値だけは、論文が挙げる例に合わせてあります。)

　主張に反する例は、「好立地で接客も優れているのに、高業績ではない店舗」です。十分条件の主張を点検するときは、このような店舗がどれだけあるかを見ます。

  • 組み合わせを備えた店舗が20店舗あり、そのうち17店舗が高業績で、3店舗が高業績ではない。この3店舗が、主張に反する例です。
  • 高業績の店舗は全体で50店舗あり、そのうち17店舗がこの組み合わせを備えている。残りの33店舗は、この組み合わせを備えずに高業績を実現しています。これは、主張に反する例ではありません。

　前者の割合(17/20)が、次に説明する「一貫性」の考え方につながります。後者(17/50)は、その次の「カバレッジ」につながります。

2. 一貫性は、主張にどれだけ一貫して合っているかを示す

　一貫性は、観察された事例が、想定する集合の関係にどれだけ沿っているかを示します。2値の集合(クリスプ集合)の十分条件では、ある条件を備えた事例のうち、結果も示した事例の割合です。たとえば、ある条件の組み合わせを備えた20店舗のうち17店舗が高業績なら、一貫性は 17/20 = 0.85 です。

　ファジィ集合(所属の程度を 0 から 1 で表す集合)では、事例 \(i\) の条件への所属度を \(X_i\)、結果への所属度を \(Y_i\) として、十分条件の一貫性を、次の式で表します。

\[\text{一貫性}(X \to Y) = \frac{\sum_i \min(X_i, Y_i)}{\sum_i X_i}\]

　すべての事例で \(X_i \le Y_i\) なら、一貫性は 1 です。

　この式は、一貫している事例と一貫していない事例を、単純に数えるものではありません。条件への所属度が高い事例ほど、重みが大きくなります。また、条件への所属度が結果への所属度をわずかに上回る程度の外れは、小さな減点にとどまり、大きく上回る外れは、大きく減点されます。論文は、これが、事例を「一貫・不一貫」の2つに分けて割合を数える方法との違いだと説明しています(pp.295-297)。

　また、一貫性は、所属度の分布にも影響されます。条件への所属度が全体に低く、結果への所属度が全体に高いと、十分条件のように見えるだけで、実際には所属度の偏りが生んだ結果であることがあります。論文は、そのため、所属度を割り当てるキャリブレーションを慎重に行い、その手続きを公開して再現できるようにすべきだと述べています(pp.298-299)。

3. カバレッジは、その関係がカバーする範囲を示す

　十分条件のカバレッジは、その条件(または条件の組み合わせ)が、結果を示した事例のどれほどをカバーしているかを示します。先ほどの17店舗が、全体で50店舗ある高業績店舗の一部なら、カバレッジは 17/50 = 0.34 です。その組み合わせは、高業績と一貫して結びついていますが、高業績の店舗全体を広くカバーしているわけではありません。

　参考までにファジィ集合では、次の式です。

\[\text{カバレッジ}(X \to Y) = \frac{\sum_i \min(X_i, Y_i)}{\sum_i Y_i}\]

　論文は、2つの指標に順序をつけて使うことを求めています。まず一貫性を確かめ、そのあとでカバレッジを見ます。一貫性が十分でなければ、カバレッジが大きくても、十分条件として経験的に重要だとは評価できないからです。また、一貫性とカバレッジは、ときに逆向きに働きます。多くの条件を重ねて細かく絞り込んだ組み合わせは、一貫性が高くても、カバレッジが非常に小さくなりがちです。なお、カバレッジが測るのは、経験的な重要性であって、理論上の重要性ではないと、論文は注記しています。

4. 複数の経路には、重複する部分と固有の部分がある

　同じ結果に至る経路は、1つとは限りません。異なる条件の組み合わせが、同じ結果に結びつくことを、等結果性(equifinality)と呼びます。

　複数の経路が、同じ成功事例をカバーしているとき、それぞれのカバレッジを単純に足すと、重複して数えてしまいます。そこで論文は、各経路のカバレッジを、重複も含めた素カバレッジ(raw coverage)と、ほかの経路ではカバーされない部分を示す固有カバレッジ(unique coverage)に分けて評価します。これは、回帰分析で、説明される分散を各変数に分ける考え方に、いくぶん似ていると、論文は述べています。ただし、条件どうしの相関を取り除く話ではなく、1つの事例が複数の経路に当てはまることを扱う、と説明しています。

本論文の貢献

　1つ目は、集合の関係を評価するための、簡単な記述的指標を示したことです。論文自身は、一貫性とカバレッジが、複雑でも、まったく新しいものでもないと述べています。新しいのは、これらを集合論的な考え方と明確に結びつけたことであり、相関を前提にした通常の定量分析との違いを示したことだ、としています。

　2つ目は、必要条件についても、一貫しているだけでは足りないと論じたことです。結果の有無にかかわらず、ほとんどの事例に備わっている条件は、必要条件としての一貫性が高くても、結果の理解にはあまり役に立ちません。必要条件のカバレッジは、このような自明な条件を見分ける手がかりになります。この点は、Goertz の議論を土台にしています。

　3つ目は、複数の経路のカバレッジを、重複する部分と固有の部分に分けたことです。これにより、成功のパターンの多様性と、それぞれの経路の重みを評価できます。

ここからは、論文を踏まえた私見です。

注目すべきと感じた部分

　特に重要だと感じるのは、先に一貫性を確かめ、そのうえでカバレッジを解釈するという順序です。十分条件としての一貫性が乏しいのに、結果を広くカバーしているという理由だけで、有力な成功パターンだと評価することはできません。

　もう1つは、結論で強調されている、指標そのものを研究の目的にしないという姿勢です。Ragin は、一貫性とカバレッジを判断の助けとしつつ、分析の結果が、個々の事例や、そこで働く過程・仕組みを理解するのに役立つかを重視しています。MBA で経営事例を研究するときにも、数値と事例の中身を行き来するこの姿勢は、大切だと思います。

ビジネスへの応用を考える:成功要因の分析を丁寧にする

　たとえば、高業績の店舗を比べるとき、「価格の安さが最も重要だ」という1つの説明にまとめる前に、「好立地と優れた接客」「強いブランド力と独自の商品構成」のように、異なる組み合わせを検討できます(架空の例です)。その際には、各組み合わせについて、どれだけ一貫して高業績と結びついているか、どれだけの高業績店舗をカバーしているか、どの店舗が例外なのかを確認します。

　ただし、一貫性が高いことは、その組み合わせを導入すれば業績が上がるという、因果効果の保証ではありません。カバレッジが大きいことも、そのまま投資の優先順位を意味しません。施策を判断するには、費用、実行可能性、因果の仕組みなども検討する必要があります。

QCA への接続

　QCA の結果を読むときには、条件の組み合わせの式だけでなく、一貫性とカバレッジ、そして対応する具体的な事例を確認します。「高い値が出たか」に加えて、「何についての一貫性なのか」「何を分母にしたカバレッジなのか」「どんな例外があるか」を説明できることが、分析の理解につながります。QCA の考え方は、「なぜ QCA は意思決定に向くのか」の記事でも紹介しています。

※以下、ポイントの整理

見返すときのポイント

  • 十分条件と必要条件を区別する。「条件があれば結果がある」と「結果があるなら条件がある」は、別の主張です。
  • 一貫性とカバレッジを区別する。十分条件では、前者は関係の一貫性、後者は結果をカバーする範囲です。先に一貫性を確かめてから、カバレッジを見ます。
  • 一貫性の値だけで判断しない。論文は、クリスプ集合の説明の中で、0.75 を下回ると、大まかな集合の関係さえ主張しにくくなると述べています。ただし、0.75 以上なら妥当という意味ではなく、事例の数と中身も確かめる必要があります。
  • 必要条件では、分母が入れ替わる(下の表)。
  • 指標は、記述的な評価です。因果効果を証明するものではありません。

　下の表では、\(M = \sum_i \min(X_i, Y_i)\) とします。

評価する関係 一貫性 カバレッジ
\(X\) が \(Y\) の十分条件 \(M / \sum_i X_i\) \(M / \sum_i Y_i\)
\(X\) が \(Y\) の必要条件 \(M / \sum_i Y_i\) \(M / \sum_i X_i\)

　必要条件のカバレッジは、十分条件の「結果全体をどれだけ網羅するか」とは、読み方が違います。必要条件とされる X の集合が、結果 Y の集合に比べて大きすぎず、経験的に自明な条件になっていないかを見る指標です。

用語解説

  • QCA(質的比較分析): 事例を条件の組み合わせとして捉え、集合の関係と論理的な比較から、結果との関係を調べる方法。
  • 条件(condition): QCA で、結果を説明する側の変数(この記事の \(X\))を指す呼び方。
  • アウトカム(outcome): QCA で、説明したい結果(この記事の \(Y\))を指す呼び方。この記事では、読みやすさを優先して「結果」と書く。
  • クリスプ集合(crisp set): 所属を 0 か 1 で表す集合。
  • ファジィ集合(fuzzy set): 所属の程度を 0 から 1 の値で表す集合。値は、概念の意味に即してキャリブレーション(較正)する。
  • 一貫性(consistency): 想定した集合の関係に、事例がどれだけ一貫して沿っているか。
  • カバレッジ(coverage): 一貫した関係の、経験的な重要性。十分条件では、結果をカバーする範囲。
  • 等結果性(equifinality): 異なる条件の組み合わせが、同じ結果に結びつくこと。
  • 素カバレッジ・固有カバレッジ(raw / unique coverage): ある経路がカバーする範囲全体と、そのうち、ほかの経路ではカバーされない部分。
  • 自明な必要条件(trivial necessary condition): 結果の有無にかかわらず広く存在し、必要条件として一貫していても、結果の理解に役立たない条件。

原典で確かめてほしいこと

　この記事は、原典の要点を私の言葉で整理したものです。原典を読むときは、次の3か所から入ると、全体をつかみやすいと思います。

  • 導入(pp.291-292): 集合の関係で述べられた理論を、相関の仮説に置き換えると、何が問題になるのか。
  • 図1と図2の説明(pp.294-297): 散布図に、集合の関係はどのように現れるのか。相関で見ると「誤差」に見える事例が、なぜ主張に反しないのか。
  • 結論(pp.309-310): なぜ、指標の高さよりも、事例の理解が重要だとされるのか。
