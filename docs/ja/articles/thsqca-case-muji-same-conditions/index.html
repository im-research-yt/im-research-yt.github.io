ThS-QCA を使ってみる(2)ユニクロの物差しで、無印良品を測ってみる

marketing
tutorial
ユニクロ用に選んだ4つの条件を、そのまま無印良品に当てはめると、十分条件がどう変わるかを確かめる記事です。
Published

November 6, 2026

連載第2弾。この記事だけで読めるように書いています。

前回(第1弾)は、ユニクロの「推奨」の線引きを9点から5点まで動かし、7〜8点以上では、ベーシックとは認識されていない状態で、価格×品質×着回しがすべて揃うことが十分条件になることを示しました。では、このユニクロ用の物差しを、そのまま無印良品に当てはめると、何が見えるでしょうか。

方法とデータ(連載共通)

  • 方法:Threshold-Sweep QCA(ThS-QCA)。「友人や知人に勧めたい度合い」(0〜10点。0=まったく勧めたくない、10=ぜひ勧めたい)の線引き（閾値）を動かしながら、推奨をもたらす十分条件(その組み合わせを持つ人の多くが、推奨に至っている組み合わせ)を並べて記述します(Toyoda, 2026, Quality & Quantity)。最適な閾値を探す方法ではありません。
  • データ:2026年6月、法政大学大学院イノベーション・マネジメント研究科の講義「マーケティング２」で行った自主調査「カジュアルファッション調査(300名)：Freeasy社にて実施」の一部を、事例用に公開しています。対象は、スクリーニング調査で、カジュアルファッションブランドを選ぶことを「まったく意識していない」とは答えなかった人です(一般の消費者を代表する標本ではありません)。各ブランドを評価した人が分析の対象です(「わからない」は除外)。
  • 対象:無印良品を評価した251名。
  • 条件(X):ユニクロと同じ4つの認識(「買いやすい価格帯」「品質がよい」「着回しやすい」「トレンドを抑えた商品がある(以下、ベーシック)」)。各ブランドについて、「あてはまると思う項目をすべて選ぶ」形式で聞き、選ばれた/選ばれなかったで分けています。ここで取り上げる4つは、手法の使い方を示す例です。例示に適したものを、結果を見て選んでいます。実際の分析では、事前に、仮説や先行研究にもとづいて、条件を決める必要があります。
  • 一貫性:その組み合わせを持つ人のうち、推奨した人の割合(基準は0.80以上)。カバレッジ:推奨した人のうち、その組み合わせで説明できた人の割合。
  • 設定(全レベル共通):最小事例数4。中間解を使います(データにない組み合わせにも、「その認識があれば推奨に寄与する」という方向の仮定を置いて、式を短くします。ただし、ベーシックだけは、どちらの方向とも決められないため、方向の仮定を置きません)。

結果:同じ物差しで、同じ線引きを動かす

7点以上 46%(58%) なし − −

(「/」は「または」、「〜でない」は、その認識が選ばれなかったことです。表の一貫性とカバレッジは、「/」で結んだ解全体の値です。)

  • 無印良品で十分条件が得られるのは、6点以上までです。ユニクロでは8点以上まで得られました。
  • ユニクロでは、7〜8点以上で、ベーシックとは認識されていない状態で、価格×品質×着回しがすべて揃うことが十分条件でした。無印良品では、この形は、6点以上で初めて現れます。
  • 6点以上のもう1つの形は、価格も着回しも認識されていない状態で、品質があれば十分、というものです。価格の認識がなくても、品質だけで推奨に至る人が目立ちます。
  • 認識の持たれ方も違います。「買いやすい価格帯」と認識する人は、ユニクロで44%、無印良品で30%でした。

つまり、共通の4条件を使ったところ、無印良品では、7点以上で基準を満たす解が得られませんでした。7点以上の割合も、ユニクロ58%、無印良品46%と異なります。同じ条件・設定でも、得られる解は、ブランドによって異なりました。

マーケティング的な読み方(仮説として)

結果から言えるのは、「どの認識の組み合わせを持つ人が、どの程度の推奨に至っているか」までです。以下は、そこから考えられる、マーケティング上の解釈で、あくまで仮説です。

  1. 同じ条件・設定でも、解の得られ方が違います。ユニクロでは、8点以上で解が得られました。無印良品では、6点以上でようやく解が得られます。ユニクロの推奨に当てはまった「価格・品質・着回し」を中心とした見方は、そのまま無印良品に持ち込めるとは限りません。
  2. 価格の認識の持たれ方が違います。「買いやすい価格帯」が選ばれた割合は、ユニクロの44%に対して、無印良品は30%です。6点以上では、価格が選ばれていない状態で、品質があれば十分、という形も現れます。ただし、これは認識の割合の違いです。無印良品を薦める人が価格を見ていない、とまでは言えません。
  3. 5点以上では、ユニクロと無印良品で、「ベーシック」の現れ方が違います。ユニクロの解には、「ベーシックでない」が含まれていました。無印良品の5点以上の解には、「ベーシック」そのものが含まれます。ただし、無印良品でベーシックが選ばれた人は8%と少数です(ユニクロは11%)。この点は、第3弾でもう一度見ます。

読むときの注意

  • この4つの条件は、ユニクロの分析用に選んだ例示です。別の条件を選べば、無印良品の結果は変わります。
  • 「十分条件が得られなかった」は、「理由がない」という意味ではありません。
  • 講義の一環で実施したオンライン調査(300名)であり、一般の消費者を代表する標本ではありません。

再現用コード(R)

データ(同じフォルダ): fashion_muji.csv

library(QCA); library(ThSQCA)
dat   <- read.csv("fashion_muji.csv")
conds <- c("PRICE", "QUALITY", "VERSATILE", "BASIC")
res <- otSweep(dat = dat, outcome = "REC", conditions = conds,
  sweep_range = 5:9,
  thrX = setNames(rep(1, length(conds)), conds),
  include = "?", dir.exp = ifelse(conds == "BASIC", "-", "1"),
  incl.cut = 0.80, n.cut = 4)
res$summary[, c("thrY", "expression", "inclS", "covS", "n_solutions")]
